# Contributing to Stack Duel

Thanks for your interest in contributing! Stack Duel is open source and we welcome help from anyone.

## Can I open a pull request?

Yes — anyone can. You don't need any special access:

1. Fork the repo you want to change (`web`, `server`, or `infrastructure`).
2. Make your changes on a branch in your fork.
3. Open a pull request back to the `main` branch of the original repo.

No org membership or role is required to submit a PR. A maintainer will review it and merge if it looks good.

## Access levels

As you contribute more, you may be given additional access:

| Level | Who | Can do |
|---|---|---|
| Everyone | Any GitHub user | Fork, open issues, open PRs |
| `triage` team | Active issue responders | Label, triage, close/reopen issues (no code write access) |
| `write` team | Proven contributors (several merged PRs) | Push branches, merge PRs, manage issues directly |
| Admin/Owner | Core maintainers | Full repo/org administration |

If you've landed a few quality PRs and want to help triage issues or get merge access, open an issue or mention it in your PR — a maintainer will add you to the appropriate team.

## Guidelines

- Keep PRs focused — one logical change per PR.
- Include a clear description of what changed and why.
- Make sure existing tests pass, and add tests for new behavior where it makes sense.
